# This is a placeholder PKI tree

Only directory layout and `vars.example` are tracked.

A real Easy-RSA PKI will additionally contain files such as:

- `ca.crt`
- `private/ca.key`
- `issued/server.crt`
- `private/server.key`
- `index.txt`
- `serial`
- `crl.pem`

Do **not** replace these placeholders with production files in Git.
